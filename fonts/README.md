# Шрифты для проекта "Генератор Баннеров"

В эту директорию необходимо поместить файлы шрифтов в формате `.ttf` или `.otf`.

## Список необходимых шрифтов:

1.  **Golos Text Regular**:
    -   Имя файла: `GolosText-Regular.ttf`
    -   Источник: https://fonts.google.com/specimen/Golos+Text

2.  **Tenor Sans Regular**:
    -   Имя файла: `TenorSans-Regular.ttf`
    -   Источник: https://fonts.google.com/specimen/Tenor+Sans

3.  **Fira Sans Regular**:
    -   Имя файла: `FiraSans-Regular.ttf`
    -   Источник: https://fonts.google.com/specimen/Fira+Sans

4.  **Igra Sans Regular** (или альтернатива):
    -   Имя файла: `IgraSans-Regular.ttf`
    -   Источник: Найдите в интернете или используйте альтернативу, например, Montserrat.
    -   Альтернатива (Montserrat): https://fonts.google.com/specimen/Montserrat

Убедитесь, что имена файлов в этой папке точно соответствуют именам, указанным в коде (`banner_generator.py`).
