# Banner Bot

Telegram бот для генерации баннеров с возможностью настройки размеров, цветов, шрифтов, текста и постпечатной обработки.

## 📋 Описание

Бот позволяет пользователям создавать баннеры через интерактивный интерфейс в Telegram. Поддерживает:
- Настройка ширины и высоты баннера
- Выбор цвета фона и текста
- Выбор шрифта
- Ввод многстрочного текста
- Масштабирование отдельных строк текста
- Добавление постпечатной обработки (люверсы)
- Предварительный просмотр перед генерацией финального PDF

## 🛠️ Технологии

- **Python 3.10+**
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) - библиотека для работы с Telegram Bot API
- [Pillow](https://python-pillow.org/) - обработка изображений
- [ReportLab](https://www.reportlab.com/) - генерация PDF
- [python-dotenv](https://pypi.org/project/python-dotenv/) - загрузка переменных окружения
- Docker для удобного развертывания

## 🚀 Запуск

### Вариант 1: Локальный запуск

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` в корне проекта с необходимыми переменными:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   TELEGRAM_CHANNEL_ID=ID_канала_для_отправки_баннеров
   ADMIN_TELEGRAM_ID=ваш_ID_в_Telegram
   ```
4. Запустите бота:
   ```bash
   python -m src.main
   ```

### Вариант 2: Через Docker

1. Убедитесь, что у вас установлен [Docker](https://www.docker.com/get-started)
2. Создайте файл `.env` в корне проекта (как описано выше)
3. Соберите и запустите контейнер:
   ```bash
   docker-compose up --build
   ```

## 🔧 Конфигурация

Все настройки находятся в файле `src/config.py`:

- `TELEGRAM_BOT_TOKEN` - токен вашего бота (обязательно)
- `TELEGRAM_CHANNEL_ID` - ID канала для отправки готовых баннеров (обязательно)
- `ADMIN_TELEGRAM_ID` - ID администратора для получения уведомлений
- Константы для размеров баннера (`MIN_DIMENSION`, `MAX_DIMENSION`, `SAFE_ZONE_MM`)
- Опции постпечатной обработки (`POSTPRINT_OPTIONS`)
- Доступные шрифты и цвета
- Состояния диалога бота

## 📱 Использование бота

1. Найдите своего бота в Telegram и отправьте команду `/start`
2. Следуйте инструкциям бота для настройки:
   - Установите ширину и высоту баннера
   - Выберите цвет фона и текста
   - Выберите шрифт
   - Укажите количество строк текста
   - Введите текст для каждой строки
   - По желанию отрегулируйте масштаб отдельных строк
   - Выберите тип постпечатной обработки
   - Просмотрите предварительный просмотр
   - Подтвердите генерацию баннера
3. Готовый баннер в формате PDF будет отправлен в указанный канал

## 🎨 Поддерживаемые форматы

- **Ввод размеров**: миллиметры (mm)
- **Цвета**: предопределенные палитры (белый, черный, красный, желтый, синий, зеленый)
- **Шрифты**: Golos Text, Tenor Sans, Fira Sans, Igra Sans
- **Постпечатная обработка**: 
  - Без люверсов
  - 4 по углам
  - Через 0.25м
